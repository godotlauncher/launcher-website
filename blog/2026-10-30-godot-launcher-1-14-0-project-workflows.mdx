Godot Launcher 1.14 adds project duplication, so you can use an existing project as the starting point for something new. This release also adds terminal commands for installed editors and bulk actions for managing your project list.

<!-- truncate -->

## Take a project in a new direction

Duplicate a prototype for an experiment, or start another project from work you already have. You can copy its editor preferences and game save data along with the project files.

You can also bring existing work into the launcher by scanning a folder or importing projects registered with Godot Project Manager. The [project guides](https://docs.godotlauncher.org/projects/manage-projects/) cover importing and duplication.

## Choose which Godot your terminal opens

If you keep different Godot versions for different projects, give each editor its own terminal command. Choose which version opens with `godot`, and use named commands for the others. The launcher can create them automatically when you install an editor.

## Manage a growing project list

Change tags or pins for several projects at once. You can arrange the **Pinned**, **New** and **Recents** groups, and open pinned projects from the system tray.

**Run project** starts a game's main scene directly from the launcher. Open the project in Godot first if it needs asset imports, a C# build or main-scene setup. You can also open a project's code editor on its own or alongside Godot.

## A few worthwhile fixes

The Light theme has been fixed, restoring its intended colours and flat controls. This release also improves Linux AppImage compatibility when launching Godot and external tools.
