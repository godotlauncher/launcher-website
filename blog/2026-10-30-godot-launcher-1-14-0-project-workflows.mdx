Godot Launcher 1.14.0 adds more ways to bring projects into your workspace, duplicate them and run them directly. It also lets you choose a default `godot` terminal command and give installed editors their own named commands.

<!-- truncate -->

## Bring projects together

Scan a folder for existing projects, or import projects already registered with Godot Project Manager. Review project names, editors and tags before adding them. Your source projects stay in their current folders, and you can choose whether an import downloads missing editors.

Duplicate a project when you want an independent copy. Choose a destination, optionally copy editor preferences or game save data, and start fresh Git history or publish the new project to a private GitHub repository.

## Choose your Godot terminal commands

Set an installed editor as your default `godot` command, or create a named alias such as `godot472`. Each editor's Settings groups its command controls together. **Settings > Command line** can create aliases automatically for new editors or help create missing aliases for existing installations.

Prerelease commands keep their stage and number: `4.8-beta1` suggests `godot48b1`, while beta2 suggests `godot48b2`. Existing aliases keep their names. Terminal commands use Godot's normal editor preferences; projects opened through Godot Launcher retain their separate per-project preferences.

## Organise and run projects

Select several projects to edit tags, clear New status, pin or unpin them, or remove them from the list together. Choose the order of Pinned, New and Recents, and open pinned projects from the system tray in your chosen order.

**Run project** starts a project's main scene without opening the Godot editor. Open the project in Godot first when it needs asset imports, a C# build or main-scene setup. Godot error messages now appear as warnings without falsely claiming that a running project has failed.

You can also open the configured code editor directly or alongside Godot, and cancel editor downloads from Projects and Create Project.

## A place for future extensions

The new **Extensions** page introduces upcoming ways to extend and customise Godot Launcher and links to the community discussion. Extensions are not available yet. GitHub connections remain under **Settings > Connections**.
